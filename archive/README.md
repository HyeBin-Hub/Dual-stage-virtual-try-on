# 연구 원본

`original/`에는 드라이브의 `viton code` 폴더에서 가져온 32개 파일을 원래 이름과 bytes 그대로 보존했습니다. 이 폴더는 현재 실행 경로에 포함되지 않습니다.

원본 README는 CP-VTON 재구현을 설명하고, 원본 environment는 이전 CP-VTON 환경입니다. 이 연구의 최종 실험 환경과 동일하다고 해석하면 안 됩니다. 일부 도구는 파일을 import하기만 해도 지정 경로의 데이터를 처리합니다. 현재 실행 방법은 root README와 `docs/reproduction.md`를 따르세요.

원본과 정리본의 차이는 `docs/validation.md`에 기록했습니다.
